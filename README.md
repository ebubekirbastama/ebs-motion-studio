# 🎬 EBS Motion Studio

> **Professional Layer-Based Social Video Editor**\
> Build stunning social media videos with a modern layer-based workflow
> powered by **Python** and **FFmpeg**.

## ✨ Features

-   🎞️ Layer-based editor
-   🖱️ Drag & Drop media
-   🎬 Video over Video
-   🖼️ Image & Logo overlays
-   🎵 Background music
-   🔇 Per-video mute/unmute
-   ✂️ OBS-style crop (Ctrl)
-   📐 Resize & Scale
-   🔄 Rotate & Position
-   👀 Live Preview
-   🎨 Modern transitions
-   📦 Automatic Output folder
-   ⚡ GPU Encoding (NVENC / QSV / AMF)
-   📱 Instagram / TikTok / Shorts presets
-   💾 Project save/load
